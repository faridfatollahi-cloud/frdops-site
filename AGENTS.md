# Agent Instructions — frdops-site

## Canonical governance

This repository is governed solely by the ChatGPT conversation designated **`FRD Ops Site — Governance`** by the repository owner.

Other agents, chats, projects, Codex/Work sessions, scheduled tasks, and automation runners are execution/proposal lanes only. They do not acquire governance authority by being asked to work on this repository.

Before making a material change, preserve the rules in `GOVERNANCE.md` and the current state in `docs/governance/FRDOPS_SITE_USCP.md`.

## Non-negotiable boundaries

- Do not commit OAuth client secrets, `Auth.json`, access tokens, refresh tokens, API keys, passwords, private Drive content, or private project runtime state.
- Do not redefine this repository as DMB-, WIOS-, PMW-, TPD-, or other-project-owned infrastructure.
- Do not broaden Google OAuth scope claims or change privacy/terms claims without explicit governance authorization.
- Do not claim Google verification, Production OAuth status, DNS verification, HTTPS activation, or other external state without evidence.
- Keep the site static, public, minimal, and project-neutral unless governance explicitly changes that architecture.
